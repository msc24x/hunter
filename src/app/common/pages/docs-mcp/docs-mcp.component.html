Connect AI assistants to Hunter and let them run your contests



Hunter has a built-in MCP (Model Context Protocol) endpoint. When you connect an AI tool like Devin, Claude, or Cursor, it can fetch your contests, create and edit questions, upload test files, run solutions on the judge, check contest quality, and publish the contest for you.

Access is host-only and follows the same permissions as the Hunter web app. An agent can only work on contests that you own.

Create an API token

Open your account page and create an API token under API Tokens. Hunter shows the raw token only once, so copy it immediately. If you lose it, revoke it and create a new one.

Sign in to Hunter first. Then open your account page, go to the Settings tab, and create an API token under API Tokens. Hunter shows the raw token only once, so copy it right away.

Endpoint details

  • URL: {{ mcpEndpoint }}
  • Auth: send your token in the Authorization: Bearer <token> header. Session cookies also work if your client supports them.
  • Protocol: MCP over HTTPS using the Streamable HTTP transport. It is stateless, so there is nothing to manage.

Available tools

After connecting, the agent can use these tools:

  • get_contests - lists your contests with filters
  • get_contest - shows a contest and its questions
  • get_contest_quality - checks whether a contest is ready to publish
  • create_contest / update_contest
  • get_questions, create_question, update_question, delete_question
  • import_questions - adds up to 10 questions at once
  • upload_question_file - uploads test cases and solutions for coding questions
  • verify_question - runs a solution on the judge

Tips for coding questions

The test and solution files you upload for a coding question are the real judging files. Tell the agent what the problem is and ask it to write many varied tests that cover edge cases and boundary values. The solution file must contain the exact expected output for every test, in the same order.

New contests start private. Run get_contest_quality before you publish. If a coding question is not verified, Hunter keeps the contest private, just like in the web editor.
